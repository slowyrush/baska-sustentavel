# baska-sustentavel
Um jogo divertido de basquete sustentável onde o objetivo é lançar cada tipo de lixo na lixeira correta. Use mira, estratégia e precisão para marcar pontos, superar desafios e avançar de fase. Aprenda sobre reciclagem enquanto compete em partidas rápidas, coloridas e cheias de ação, habilidade e diversão ecológica.
